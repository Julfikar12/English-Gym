# English Gym by Julfikar

প্রতিদিন ১০ মিনিটে ইংরেজি — বাংলাদেশিদের জন্য ফ্রি ওয়েব অ্যাপ। কোনো লগইন, সার্ভার বা খরচ লাগে না।

## কী কী আছে
- **ডেইলি ওয়ার্কআউট:** ৫টা শব্দ (উচ্চারণসহ) → ৫টা কমন ভুল → ৩টা বাংলা থেকে ইংরেজি → ১টা কাজের ফ্রেজ
- **Mistakes Hunter:** ২১৬টা বাস্তব কমন ভুলের কুইজ, বাংলায় ব্যাখ্যা, সার্চ আর বিষয়ভিত্তিক ফিল্টার
- **গল্পে শিখুন:** বাংলাদেশের পরিবেশে ছোট ইংরেজি গল্প, শব্দে চাপ দিলে মানে
- **কাজের ফ্রেজ:** অফিস, ক্লায়েন্ট, ইন্টারভিউ, ইমেইল — ক্যাজুয়াল আর প্রফেশনাল দুইভাবে
- **স্ট্রিক, XP, লেভেল, ব্যাজ, ৩০ দিনের চ্যালেঞ্জ**
- **শেয়ার কার্ড:** স্কোর/স্ট্রিক/আজকের ভুল ছবি হিসেবে ফেসবুকে শেয়ার
- অফলাইনেও চলে, মোবাইলে "Add to Home Screen" দিলে অ্যাপের মতো

## ফাইলগুলো
| ফাইল | কাজ |
|---|---|
| `index.html` | ডিজাইন ও পেজ |
| `app.js` | অ্যাপের লজিক |
| `data.js` | সব কনটেন্ট (ভুল, শব্দ, গল্প, ফ্রেজ) — নতুন কনটেন্ট এখানে যোগ করুন |
| `sw.js` | অফলাইন সাপোর্ট |
| `manifest.webmanifest`, `icons/` | মোবাইলে অ্যাপ হিসেবে ইনস্টল |

## কনটেন্ট আপডেট করলে
`data.js` বদলানোর পরে `sw.js` ফাইলে `VERSION = 'eg-v1'` কে `'eg-v2'` করে দিন, যাতে সবার ফোনে নতুন ভার্সন আসে।

# English Gym by Julfikar

প্রতিদিন ১০ মিনিটে ইংরেজি — বাংলাদেশিদের জন্য ফ্রি ওয়েব অ্যাপ। কোনো লগইন, সার্ভার বা খরচ লাগে না।

**লাইভ:** https://julfikar12.github.io/English-Gym/

## কী কী আছে
- **ডেইলি ওয়ার্কআউট:** ৫টা শব্দ (সমার্থকসহ) → ৫টা কমন ভুল → ৩টা বাংলা থেকে ইংরেজি → ১টা কাজের ফ্রেজ
- **Mistakes Hunter:** ২১৬টা কমন ভুল, ৩টা মোড (ক্লাসিক, সত্য/মিথ্যা, ৬০ সেকেন্ডের স্পিড রাউন্ড)। সব ভুল শেষ না হওয়া পর্যন্ত কোনো প্রশ্ন রিপিট হয় না।
- **শব্দভান্ডার:** ৩০৩টা শব্দ — মানে, উদাহরণ, ২-৩টা সমার্থক শব্দ, শব্দ কুইজ, গল্পে শেখা
- **দৈনন্দিন বাক্য:** বাসা, খাবার, বাজার, যাতায়াত, ফোন, স্বাস্থ্য, অফিস সহ ১৭১টা বাক্য
- **ফ্রিল্যান্সার কর্নার:** প্রথম মেসেজ থেকে পেমেন্ট ও রিভিউ পর্যন্ত ২১টা ধাপে ৫২৬টা ক্লায়েন্ট বাক্য, বাংলা মানেসহ, অনুশীলন মোড
- **কিডস কর্নার:** ABC, ১২২টা ছবির শব্দ, রং, সংখ্যা, ৪টা গেম (ছবি দেখে বলো, শুনে খোঁজো, বানান, মেমোরি)
- **প্রোগ্রেস:** স্ট্রিক, XP, ৫টা লেভেল, ১১টা ব্যাজ, ৩০ দিনের চ্যালেঞ্জ
- **অনুশীলন স্টুডিও (নতুন):** বলো শুনি (মাইকে বললে অ্যাপ শুনে শব্দ ধরে ধরে মিলিয়ে দেয়, নিজের গলা রেকর্ড), উচ্চারণ ক্লিনিক (V/B, W/V, F/P, S/SH, Z/J, TH, ship/sheep, bed/bad, L/R), বাক্য বানাও (শব্দ সাজিয়ে বাক্য), শুনো আর লিখো (৩ গতিতে ডিক্টেশন), বন্ধুকে চ্যালেঞ্জ (একই ১০ প্রশ্নের লিংক, স্কোর পাশাপাশি)
- **গ্রুপ রুম (নতুন):** কোড দিয়ে প্রাইভেট গ্রুপ, টেক্সট চ্যাট, লাইভ চ্যালেঞ্জ (সবাই একই প্রশ্ন, লাইভ স্কোরবোর্ড), Jitsi ভয়েস রুম। Firebase Realtime Database (ফ্রি Spark প্ল্যান) দিয়ে চলে, সেটিংস `config.js` এ।
- **শেয়ার কার্ড:** স্কোর/স্ট্রিক/আজকের ভুল ছবি হিসেবে ফেসবুকে
- **প্রিমিয়াম প্রস্তুত:** বিকাশ/ব্যাংক পেমেন্ট + আনলক কোড (এখন বন্ধ, সব ফ্রি)
- অফলাইনেও চলে, মোবাইলে "Add to Home Screen" দিলে অ্যাপের মতো

## ফাইলগুলো
| ফাইল | কাজ |
|---|---|
| `config.js` | **আপনার সেটিংস** — ফেসবুক, হোয়াটসঅ্যাপ, বিকাশ নাম্বার, দাম, প্রিমিয়াম চালু/বন্ধ |
| `data.js` | কমন ভুল, গল্প, অনুবাদ, ফ্রেজ |
| `data-words.js` | শব্দভান্ডার |
| `data-daily.js` | দৈনন্দিন বাক্য |
| `data-freelance-1.js`, `data-freelance-2.js` | ফ্রিল্যান্সার বাক্য |
| `data-kids.js` | কিডস কর্নার |
| `data-practice.js` | উচ্চারণ ক্লিনিকের শব্দজোড়া |
| `app.js`, `index.html` | অ্যাপ ও ডিজাইন |
| `tools/make-codes.js` | প্রিমিয়াম আনলক কোড বানানোর টুল |

## প্রিমিয়াম চালু করতে
1. `config.js` এ `bkash`, `whatsapp`, দাম বসান।
2. কম্পিউটারে `node tools/make-codes.js 20` চালান। কোডগুলো নিজের কাছে রাখুন, hash গুলো `codeHashes` এ বসান।
3. `enabled: true` করে সেভ করুন।
4. কেউ পেমেন্ট করে TrxID পাঠালে মিলিয়ে দেখে একটা কোড দিন।

## কনটেন্ট আপডেট করলে
`sw.js` ফাইলে `VERSION` এর সংখ্যা বাড়িয়ে দিন (যেমন `eg-v2` → `eg-v3`), যাতে সবার ফোনে নতুন ভার্সন আসে।
